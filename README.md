# JavaScript

Repositório de estudos, exercícios e projetos relacionados à linguagem JavaScript.

O objetivo é centralizar atividades práticas desenvolvidas durante o aprendizado da linguagem, incluindo conteúdos de diferentes períodos que anteriormente estavam distribuídos em dispositivos distintos.

## Conteúdo

- Fundamentos da linguagem JavaScript
- Variáveis e tipos de dados
- Estruturas condicionais e de repetição
- Funções
- Arrays e objetos
- Manipulação do DOM
- Eventos
- Programação assíncrona
- Exercícios e projetos práticos

## Objetivo

Centralizar materiais práticos relacionados ao aprendizado de JavaScript e acompanhar a evolução dos conhecimentos em desenvolvimento web.

## Tecnologias

- JavaScript

As versões e bibliotecas utilizadas podem variar conforme a atividade ou projeto armazenado no repositório.

## Como utilizar

Clone o repositório:

```bash
git clone https://github.com/bispobr/JavaScript.git
cd JavaScript
```

Como o repositório reúne diferentes atividades e projetos, cada diretório pode possuir seus próprios requisitos e instruções de execução.

Quando uma atividade for executada no navegador, abra o respectivo arquivo HTML em um navegador compatível ou utilize um servidor local, conforme a estrutura do projeto.

## Organização

Os conteúdos são organizados conforme os estudos e projetos adicionados ao repositório. A estrutura pode evoluir à medida que novas atividades forem incorporadas.

## Status
